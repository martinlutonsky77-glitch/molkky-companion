MÖLKKY COMPANION – GITHUB AUTO-BUILD

Repo: martinlutonsky77-glitch/molkky-companion

Do GitHub repozitáře patří pouze obsah GITHUB-READY balíčku.
Podpisový klíč a hesla jsou pouze v SECURE balíčku.

V GitHubu otevři:
Settings -> Secrets and variables -> Actions -> New repository secret

Vytvoř 4 repository secrets:
MOLKKY_KEYSTORE_BASE64
MOLKKY_STORE_PASSWORD
MOLKKY_KEY_ALIAS
MOLKKY_KEY_PASSWORD

Přesné hodnoty jsou v SECURE balíčku v souboru GITHUB-SECRETS-VALUES.txt.

Workflow .github/workflows/release-apk.yml klíč při buildu obnoví pouze do dočasného GitHub runneru a vytvoří podepsané APK.

Nové vydání:
1. zvýšit versionCode
2. zvýšit versionName a currentVersion
3. commitnout změny
4. vytvořit tag např. v1.5.0
5. GitHub Actions vytvoří APK a GitHub Release
